# Dr. Garg Learning Games

Live site: https://kashee12345.github.io/dr-garg-games/

Free browser study games by Dr. Akash Garg. No account, no install; progress stays in your browser, and each game has a Save code to move it to another device.

| Game | What it is | Link |
|---|---|---|
| Kingdom of Corpus | A&P adventure: 15 lands, 900 questions, about 150 diagrams, spaced review and skill drills | [play](https://kashee12345.github.io/dr-garg-games/kingdom-of-corpus/) |
| Kingdom of Corpus: Adventure Edition | Adds physiology shrines, two phase guardians, villager cases, muscle training and a Lore Codex | [play](https://kashee12345.github.io/dr-garg-games/kingdom-of-corpus-adventure/) |
| Chiro Mystery | NBCE Part III style clinic: 200 patient cases, mock board exams, real radiographs | [play](https://kashee12345.github.io/dr-garg-games/chiro-mystery/) |
| Exam Day | Part IV style exam day: 48 patient stations, a technique station, SOAP note feedback | [play](https://kashee12345.github.io/dr-garg-games/exam-day/) |
| Film Room | X-ray reading trainer: 266 real films, measuring lab, walkable reading room | [play](https://kashee12345.github.io/dr-garg-games/film-room/) |

Independent practice tools, not affiliated with or endorsed by the NBCE or any school. Practice scores do not predict official results; patient cases are teaching cases, not clinical rules.
